# Index - Vault

Indgangen til de frie noter i AI OS-vaulten. Alt her er **noter** — ikke styrede filer.
De styrede filer (`CLAUDE.md`, `AGENTS.md`, `INDEX.md`, `agents/`, `tools/`) og
projektfilerne under `AI-SOSU/` følger deres egne regler og hører ikke i denne mappe.
Se `CLAUDE.md` → *Obsidian-vaultregler* for scope og routing.

> [!info] Hvor lander en ny note?
> Obsidian er sat op til at lægge nye filer i `vault/inbox/` og daglige noter i
> `vault/journal/`. Roden holdes ren — den er dækket af startkontrollen.

## Mapper

| Mappe | Indhold | `type:` |
|---|---|---|
| `inbox/` | Uforarbejdet — flyttes videre når det er bearbejdet | – |
| `journal/` | Daglige noter, `YYYY-MM-DD.md` | daily |
| `notes/` | Permanente noter | note |
| `notes/people/` | Personer, `Fornavn Efternavn.md` | person |
| `notes/decisions/` | Beslutninger, `YYYY-MM-DD - Beslutning.md` | decision |
| `meetings/` | Møder, `YYYY-MM-DD - Mødetitel.md` | meeting |
| `resources/` | Kilder og referencer | resource |
| `_templates/` | Skabeloner: [[Daily]], [[Note]], [[Meeting]], [[Decision]] | – |
| `_attachments/` | Vedhæftninger | – |
